PR 6075: a phone book for NFT collections

Explainer for gnolang/gno#6075, last of the GRC721 series. Generated by claude-opus-5. No review state on this page: Review files.

What it adds

A realm at r/demo/defi/grc721reg where any realm may list its NFT collection so wallets, marketplaces and other realms can find it by name instead of by import. It is the direct counterpart of r/demo/grc20reg, which does the same for fungible tokens, and the file follows it closely: 172 lines of realm code and 432 of tests.

The key

An entry is filed under the registering realm's own path, plus an optional slug for a realm running more than one collection.

gno.land/r/alice/punks          slug omitted
gno.land/r/alice/punks.summer   slug "summer"

Registration checks that the collection was issued by the caller: a token's id starts with the path of the realm that created it, so the registry compares that prefix against the caller and refuses anything else. A slug is limited to letters, digits, underscore and hyphen, up to 128 characters, and a key that is already taken is refused.

What a caller gets back

CallAnswer
Get(key)The collection, or nil.
MustGet(key)The collection, or a panic.
GetToken(key)Just the token's read side.
GetExtension(key, kind)One extension read view, plus whether it was there.
GetRegistry()The whole tree behind a read-only wrapper, for callers that want to walk it.

The trade the package doc names

grc20reg stores a concrete *grc20.Token, so what comes out is what the type says. This registry stores extension views as interface values, which is what lets it hold kinds it does not import, including kinds nobody has written yet. The cost is that the type check moves to the reader: a kind string is a label chosen by whoever registered the entry, so a consumer asserts the concrete type before trusting it.

The two pages it renders

The index, one line per collection:

- Gno Punks - gno.land/r/alice/punks - metadata royalty - info
- Sky Cats - gno.land/r/bob/cats - core only - info

And a page per collection, reached by putting the key after the colon in the URL:

Gno Punks
- symbol: PUNK
- realm: gno.land/r/alice/punks
- total supply: 1024
- extensions: metadata royalty

Both pages read the collection live, so the supply shown is the supply at the moment the page is requested.

Registering, end to end

func init(cur realm) {
    nft = collection.New("Gno Punks", "PUNK", 0, cur)
    meta, _ := metadata.NewMetadata(nft.Ledger())
    nft.Attach(meta)

    grc721reg.Register(cross(cur), nft.Token(), "", meta)
}

The call emits a register event carrying the key, the token id, the realm path, the slug, the symbol and the list of extension kinds, which is what an indexer follows to keep its own copy in step.
